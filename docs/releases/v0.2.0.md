# CinePresence 0.2.0

- Fixes the browser detection regression where an unrelated excluded-site window could block the only usable movie/episode caption. Conflicting media captions and explicitly excluded sources remain blocked.
- Adds an optional Chrome/Edge companion for streaming pages with missing tab/Windows metadata. Reads structured movie/episode data, headings and video timing, including embedded players. Supports temporary manual titles when the page exposes nothing useful.
- Preserves the social/general-video restrictions, now with domain checks for both outer pages and embedded players. No bypass through Windows duplicate sessions, manual titles or cached matches. Keeps first-playing selection, pause handoff and immediate pause clearing.
- Adds a per-user Windows installer that installs the app and prepares the companion connection, plus a guided extension-loading page. The companion is not listed in browser stores yet: **Developer mode → Load unpacked** is still required. The installer does not silently force an extension or alter browser policies.
- Keeps compact artwork popups, animated entrance/exit, seven-second auto-dismissal, TMDB artwork and actual player progress. Live buffers have no artificial countdown.

Download **CinePresence-0.2.0-Setup-win-x64.exe** for installation, or **CinePresence-0.2.0-win-x64.zip** for portable use. Both include .NET and use your existing local settings. Keep Discord open. Reload existing browser tabs after enabling the companion.

The native app and companion are tested with automated parsing, domain exclusion, source competition, local pipe and extension-message scenarios. Compatibility with arbitrary streaming players, final Discord presentation and a clean Windows account remain manual checks; see the included validation document for observed results. The installer is not code-signed.
