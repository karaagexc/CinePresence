## CinePresence 0.1.3

Automatic presence now checks whether browser playback has useful movie/show metadata before matching. Generic page names such as Facebook no longer become unrelated TMDB movies.

- Exclude Facebook, YouTube, Twitter/X, Instagram, TikTok, VK, Vimeo, Dailymotion, Reddit, Twitch, Kick, Snapchat, Pinterest, and Threads when identified. Real movie/episode names do not bypass these exclusions. Browser playback whose source cannot be established stays unshared.
- Require an explicit **Correct match** confirmation for ambiguous browser titles. Previously cached automatic results cannot bypass the guard. Keep the playing tab selected so its window context can be checked.
- Make the watching popup smaller, with a show poster, a **Change match** button, and a seven-second timeout. Add slide/fade animations, respect Windows' animation preference, and pause dismissal while hovered.
- Recognize common streaming page titles, including live shows such as NXT. Growing live buffers no longer produce a misleading countdown, and missing episode information is never invented.
- Keep automatic presence on the first playing source until it pauses, stops, closes, or is excluded. Resuming an earlier source does not steal presence back.
- Fix Windows video sessions incorrectly being skipped as music, and improve browser/VLC episode-title extraction across shows and websites.

### Install

Download **CinePresence-0.1.3-win-x64.zip**, extract the entire folder, and run **CinePresence.exe** on Windows 11 x64. The ZIP includes .NET. Each user supplies their own TMDB API Read Access Token; no Discord user token is needed. Existing CinePresence settings stay in local application data.

### Validation and limits

124 automated tests passed. WPF smoke checks cover the artwork popup, animated correction action, and automatic dismissal at approximately seven seconds. Browser/site identification depends on metadata and visible window context; unidentifiable sources are skipped. Mixed-DPI monitor placement and Discord's final activity layout remain manual acceptance checks. Discord artwork remains the existing TMDB poster.
