# CinePresence 0.2.2

- Smarter automatic identification combines structured page metadata, player-adjacent titles/episode labels, release years and generic movie/TV URL hints. URL IDs are checked against TMDB before use. Series evidence prevents same-named movies from winning; ambiguous results stay unshared.
- Change match fades the compact watching popup into a searchable poster picker. Movie/series labels, years and editable season/episode fields make the fallback easier. The app uses the same picker. Normal popups still dismiss after seven seconds; editing keeps them open.
- Converts the companion source to strict TypeScript. Runtime JavaScript is generated by the build and development dependencies are excluded from releases.
- Fixes the generic Windows icon with an embedded multi-size CinePresence icon for the executable, tray, installer and companion.
- Includes the optional Chrome/Edge companion and per-user installer, native browser/VLC detection fixes, first-playing source lock and pause handoff. Social/general-video restrictions still apply to outer pages, embedded players, corrections and duplicate Windows sessions.
- Makes upgrades safe while the companion is connected: its own local connection is briefly suspended during file replacement and restored on completion or cancellation. Edge and Chrome stay open.
- Rechecks old automatic matches while preserving saved corrections and encrypted settings.

Download **CinePresence-0.2.2-Setup-win-x64.exe** to install/update, or **CinePresence-0.2.2-win-x64.zip** for portable use. Both include .NET. Keep Discord open and enter your own TMDB read token.

**Companion update:** install into the same folder, open `edge://extensions` or `chrome://extensions`, reload CinePresence Companion, then refresh the playing tab. First installation still uses **Developer mode → Load unpacked** through the included guide; no browser-store listing exists yet. The installer prepares the connection but does not silently enable an unlisted extension.

Validated with 155 .NET tests, 17 compiled-companion tests, real TMDB checks for the reported identities, and WPF popup/picker rendering. The prior native-host and installer round-trip tests are documented in `docs/VALIDATION.md`. Compatibility with every streaming player, final Discord appearance and clean-account installation are not claimed. The installer is not code-signed.
