# CinePresence 0.2.3

- Excludes Spotify's web player and all spotify.com subdomains from browser detection, including embedded players. Manual titles, episode-like metadata and saved corrections cannot bypass the exclusion.
- Recognizes Spotify branding/domains in native browser metadata and captions. The Spotify desktop app remains excluded as a known music source.
- Keeps the animated poster picker, automatic movie/series identification, first-playing source selection and all existing platform restrictions.
- Rebuilds the README around downloads, interface previews, quick setup and compatibility; detailed behavior and developer information now live in dedicated guides.
- Migrates the remaining setup helper and Node test scripts to TypeScript. Legacy companion source scripts are removed during upgrades; browsers use only compiled output.

Download **CinePresence-0.2.3-Setup-win-x64.exe** to install/update, or **CinePresence-0.2.3-win-x64.zip** for portable use. Existing settings are preserved. Reload CinePresence Companion in `edge://extensions` or `chrome://extensions`, then refresh open playback tabs.

Validation: 166 .NET tests and 18 compiled TypeScript companion tests passed. Coverage includes Spotify desktop identities, browser captions, domain and embed filtering, explicit manual titles, and unrelated hostname lookalikes. Native Windows detection still depends on the metadata exposed by the player; the companion provides domain-based filtering.
